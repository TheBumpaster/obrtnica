# Change: Move auth-flow and shell-core into client app

**Date:** 2025-12-18  
**Change:** Removed `packages/auth-flow` and `packages/shell-core`; migrated their UI-facing code into `apps/client/src/lib/auth` and `apps/client/src/lib/shell`.

## Summary
- Client auth wrappers, error mapping, and schema re-exports now live in `apps/client/src/lib/auth`.
- Navigation/catalog helpers and permission utilities now live in `apps/client/src/lib/shell`.
- Client imports updated to use the new local modules.
- Workspaces no longer include `@serp/auth-flow` or `@serp/shell-core`.

## Impact
- API/worker unaffected (they did not depend on these packages).
- Client remains the single source for UI logic; validation schemas still sourced from `packages/validations`.

## Follow-ups
- None required; consider future consolidation of navigation catalog if server needs a derived view.
