---
title: Auth UI parity exception (mobile excluded)
date: 2025-12-18
related_backlog: backlog/v1.2.0/ui/requirement_3.md
decision: |
  Mobile (Expo) is temporarily excluded from auth UI parity for v1.2.0. Only Web (Next.js) and Desktop (Electron) will be implemented.
rationale: |
  The mobile app was removed from the monorepo per the approved maintenance plan (see docs/archive/mobile). Reintroducing mobile would require restoring the package, deps, and build pipeline; this is out of scope for v1.2.0 auth work.
impact: |
  - Auth flows ship on Web and Desktop only.
  - Mobile users have no first-class client; they must use Web as a fallback.
  - Any future mobile reinstatement must add a backlog item to restore parity.
follow_up: |
  - If mobile parity is required again, create a new backlog item to reintroduce `apps/mobile` and implement the same auth flows using the shared auth-flow layer.
risks: |
  - Mobile gap remains until explicitly planned.
  - Parity rules require this exception to be cited in release notes for auth v1.2.0.
notes: |
  This document is required by the cross-platform parity rule; it records the explicit exception so Web/Desktop work can proceed without violating policy.
